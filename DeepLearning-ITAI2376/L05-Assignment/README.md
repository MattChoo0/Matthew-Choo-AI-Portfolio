L05 focuses on implementing and comparing RNNs, Text Transformers, and Vision Transformers (ViTs).
The lab is divided into four main sections that requires both the use of provided code and original implmentation. 
Part A is RNNs where we have to follow a provided LSTM pattern to build a GRU model (Exercise 6) and a Vanilla RNN from scratch (Exercise 7), followed by hyperparameter tuning (Exercise 8).
Part B is Text Transformers where we have to fine-tuning BERT for text classification.
Part C is Vision Transformers where we also have to fine-tuning ViT for image tasks and generating attention map visualizations.
Part D is Analysis & Reflection where we have to create a comprehensive comparison table of all models and answering 10 reflection questions.
