In Lab 02, we are task to build, train and evaluate a Neural Network. 
Also have to learn how to build models using PyTorch and TensorFlow/Keras.
Then we have to compare the frameworks and tune the model to better performance.
It focuses on building, training, and evaluating neural networks by using both PyTorch and TensorFlow/Keras.
The learning objectives are understanding core neural network components like layers and activation functions, comparing the developer experience between PyTorch and TensorFlow, learning to diagnose overfitting using techniques like dropout and experimenting with hyperparameters such as learning rate and batch size.
The Objectives is understanding the core components of a neural network (layers, neurons, activation functions), building and train a neural network using both PyTorch and TensorFlow/Keras, experimenting with hyperparameters like learning rate, batch size, and epochs, diagnose and address overfitting with techniques like dropout and comparing and contrast the developer experience of PyTorch and TensorFlow. 
The assignment is divided into seven sections which are Framework Comparison: Analyzing PyTorch vs. TensorFlow, Setup & Data Prep: Preparing the Fashion-MNIST dataset, Build with PyTorch: Creating models and training loops in PyTorch, Build with TensorFlow: Recreating the model using the Keras API, Hyperparameter Tuning: Addressing overfitting with dropout, Student Challenge: Implementing mandatory model improvements and Conclusion: Summarizing takeaways.
